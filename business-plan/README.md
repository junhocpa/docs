## 운영 원칙

- **신고기한이 항상 최우선.** 구축성 태스크는 신고 마감 주간(매월 1~10일, 부가세 신고 주간)을 피해 배치한다.
- **한 번 한 일은 문서로 남긴다.** 반복된 업무는 매뉴얼화 → 자동화(Claude 스킬) 후보로 승격한다. YMK 재고수불 스킬이 선례.
- **데이터는 Airtable, 지식은 이 저장소.** 거래처·일정·수금 데이터는 Airtable로, 매뉴얼·템플릿·플랜은 docs 저장소로 관리한다.
- **매주 월요일 [schedule-checklist.md](./schedule-checklist.md) 확인, 매월 말 30분 리뷰.** 체크박스를 갱신하고 다음 달 우선순위를 조정하며, dashboard.html의 진행률을 업데이트한다.
