# 2. 아웃소싱 업무

> 목표: 진행 중인 YMK 업무를 표준 사례로 삼아, 경리·재무 아웃소싱을 정식 서비스 상품으로 만든다.

## 2.1 진행 중 업무: ㈜와이엠케이 (YMK)

월간 ERP 재고수불 자동전표 처리. 전용 Claude 스킬(`ymk-inventory-transfer`)로 운영 중이며, 아웃소싱 서비스의 표준 모델이다.

**월간 운영 사이클**
1. 자료 수취: 더존 ERP 재고현황(출고현황) 엑셀 수취 (매월 초)
2. 처리: 스킬로 타계정대체·타프로젝트대체 자동전표(19컬럼) 생성
3. 검증: 거래처매핑·검증 시트 확인, 이상 항목 수기 검토
4. 납품: 전표 워크북 전달, ERP 반영 확인

**품질 체크포인트**
- [ ] 매월 검증 시트의 미매핑·이상 항목 0건 확인 후 납품
- [ ] 마스터 데이터(거래처 매핑) 변경 발생 시 스킬 references 즉시 갱신
- [ ] 처리 소요시간 기록 → 요금 산정·개선 근거로 축적

## 2.2 서비스 상품화

| 상품 | 범위 | 비고 |
|---|---|---|
| 경리대행 (기본) | 증빙 정리, 전표 입력, 월 마감 | 기장 계약에 얹는 애드온 |
| 급여 아웃소싱 | 급여 계산, 원천세·4대보험 신고, 급여명세 발송 | 인원수 기준 과금 |
| 지출·자금관리 | 지출결의 검토, 자금일보, 이체 실행 지원 | 권한·책임 범위 계약서에 명시 |
| 결산 지원 | 월/분기 결산, 경영 리포트 | YMK형 — ERP 기반 자동화 적용 |

**실행 태스크**
- [ ] 상품별 업무 범위 정의서(포함/불포함 명시) 작성 (9월)
- [ ] 요금표 설계: 규모(거래 건수·인원수)별 월정액 + 초과 건당 요율 (9월)
- [ ] 표준 계약서(업무 범위·책임 한정 조항 포함) 작성 (9월)

## 2.3 확장 전략

- **기존 기장 고객 업셀**: 월 마감 과정에서 경리 인력 공백·급여 업무 부담이 보이는 고객에게 제안 — 10월부터 제안서 발송
- **레퍼런스 영업**: YMK 사례(ERP 자동전표 처리)를 익명화한 사례서로 제작, 제조·유통업 대상 제안에 활용
- **자동화 차별점**: "같은 비용으로 더 빠르고 정확하게" — 자동화 기반 처리를 요금·품질 경쟁력으로 내세움

**실행 태스크**
- [ ] YMK 사례서(1페이지, 익명화) 제작 (10월)
- [ ] 기존 고객 중 업셀 후보 선별(Airtable 태그) 및 제안 개시 (10월)

## 2.4 표준 프로세스 — 신규 수임 인수인계 체크리스트

- [ ] 업무 범위·요금 확정, 계약 체결
- [ ] 자료 접근 확보: ERP/회계 프로그램 권한, 스크래핑·사이트 접속정보 (→ Airtable 접속정보 테이블 등록)
- [ ] 전임자(또는 내부 경리) 업무 인수: 최근 3개월 처리 내역 검토
- [ ] 첫 달 병행 운영(기존 방식과 대사) 후 단독 운영 전환
- [ ] 월간 운영 사이클·담당자 확정, 반복 업무 자동화 후보 평가
