# 3. 영업방향 및 조직 구축

> 목표: 수임을 "우연한 소개"에서 "재현 가능한 프로세스"로 바꾸고, 채용 판단 기준을 마련한다.

## 3.1 타겟 시장·포지셔닝

**세그먼트**

| 세그먼트 | 니즈 | 접근 |
|---|---|---|
| 신규 창업자 (법인 설립·개업) | 창업 초기 세무 전반을 맡길 곳 | 설립 대행 제휴, 창업 콘텐츠 |
| 소규모 법인 (직원 1~20명) | 기장 + 급여 + 결산을 한번에 | 아웃소싱 결합 제안 |
| 개인사업자 (성장기) | 절세, 법인 전환 상담 | 소개·온라인 콘텐츠 |
| ERP 사용 제조·유통업 | 재고·전표 처리 부담 | YMK형 자동화 아웃소싱 |

**포지셔닝**: "자동화로 빠르고 정확한 기장" — 회계사 직접 관리 + AI·자동화 기반 처리를 차별점으로. 단순 저가 경쟁은 하지 않는다.

## 3.3 수임 프로세스 표준화

상담 → 견적 → 계약 → 온보딩 4단계.

1. **상담**: 상담 시트(업종, 매출 규모, 현재 기장 상태, 니즈) 작성
2. **견적**: 요금 기준표에 따라 견적 — 재량 할인 금지, 예외는 사유 기록
3. **계약**: 수임계약서 + CMS 출금동의서 + 개인정보 동의 일괄 수취
4. **온보딩**: 홈택스 수임동의, 자료 인수, Airtable 등록, 첫 달 기장 개시

**필요 양식** (→ `templates/` 폴더에 작성)
- [ ] 상담 시트 (8월)
- [ ] 요금 기준표 (8월)
- [ ] 수임계약서 표준안 (8월)
- [ ] 온보딩 체크리스트 (9월)

## 3.4 조직 구축

**채용 시점 판단 기준** (분기마다 점검)
- 기장 거래처 수가 1인당 관리 한계(예: 40~50개) 도달
- 월 마감이 상시 지연되거나, 영업·신규 업무에 쓸 시간이 없음
- 아웃소싱 수임 확대로 정형 업무량 증가

**업무분장안 (첫 직원 채용 시)**
- 직원: 증빙 수취·전표 입력·월 마감 1차, 급여 아웃소싱 실무
- 회계사(본인): 검토·신고, 상담·영업, 재산제세, 자동화 구축

**보상**: [01-internal-system.md의 급여·성과급 배분 구조](./01-internal-system.md#16-급여성과급-배분-구조)를 따른다.

**실행 태스크**
