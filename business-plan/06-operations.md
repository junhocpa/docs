# 6. 기타 업무 처리

> 목표: 정기 업무를 사이클로 고정해 누락 없이 처리하고, 행정 잡무에 원칙을 세워 시간을 지킨다.

## 6.1 월간 정기 사이클

| 시기 | 업무 |
|---|---|
| 매월 1~5일 | 스크래핑 자료 수취, 수기 증빙 요청, 급여 자료 마감 |
| 매월 10일 | **원천세(원천징수이행상황신고)·지방소득세 특별징수분 신고·납부** |
| 매월 10~15일 | 4대보험 신고 처리, 전표 입력 |
| 매월 15~20일 | 월 마감 검토 (계정 대사, 이상 거래 확인) |
| 매월 25일 | CMS 기장료 출금, 출금 결과 기록 |
| 매월 말일 | 일용근로·사업소득(인적용역) 간이지급명세서 제출, 세금계산서 발행 마감, 월말 플랜 리뷰 30분 |

## 6.3 행정 처리 원칙

**고객 응대**
- 문의는 당일 접수 확인, 48시간 내 답변. 즉답이 어려우면 예상 답변 시점을 먼저 안내
- 반복 문의(증명서 발급, 납부서 재발행 등)는 표준 답변 템플릿화 → 카카오톡용 순수 텍스트로 보관

**자료 수취 독촉**
- 매월 5일 1차 요청 → 10일 2차(마감 영향 안내) → 15일 유선. 3개월 연속 지연 고객은 계약 조건(마감 지연 면책) 재안내

**청구·수금**
- 정기 기장료: CMS 원칙 ([01-internal-system.md](./01-internal-system.md) 참조)
- 건별 업무(조정료, 재산제세 등): 착수 시 50% 선금 원칙, 완료 시 잔금 — 세금계산서 즉시 발행
- 미수 현황은 Airtable에서 월 1회 점검, 2개월 초과 미수는 업무 보류 검토

**기록**
- 모든 신고 완료는 Airtable 신고일정 테이블에 완료일 기록 — 접수증 PDF는 거래처 폴더에 보관
