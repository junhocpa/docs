# 4. 홈페이지 구축

> 목표: 10월 말까지 사무소 소개·서비스 안내·상담 문의가 가능한 홈페이지를 오픈한다.

## 4.1 목적과 성공 기준

- 소개받은 잠재 고객이 검색했을 때 신뢰를 주는 **디지털 명함**
- 상담 문의가 들어오는 **접수 채널** (전화 의존 탈피)
- 세무 정보 블로그를 통한 **검색 유입** (장기)

성공 기준: 오픈 3개월 내 홈페이지 경유 상담 문의 월 3건.

## 4.2 콘텐츠 구성안

| 페이지 | 내용 |
|---|---|
| 홈 | 사무소 소개, 핵심 차별점(회계사 직접 관리 + 자동화), 상담 버튼 |
| 서비스 | 기장·세무대리 / 경리·급여 아웃소싱 / 양도·증여·상속세 — 각 서비스 범위와 진행 절차 |
| 수수료 안내 | 기준 요금표 (문의 유도형으로 범위만 표기할지 결정) |
| 상담 신청 | 폼(이름·연락처·업종·문의 내용) 또는 카카오톡 채널 연결 |
| 세무 정보 | 블로그 (월 2회 발행 목표) |
| 사무소 소개 | 회계사 약력, 위치·연락처 |

## 4.3 구축 방식

| 방식 | 장점 | 단점 |
|---|---|---|
| 이 저장소(Mintlify) 활용 | 이미 세팅됨, 마크다운으로 관리, 무료 호스팅 | 문서 사이트 성격이 강해 마케팅 페이지로는 커스터마이징 한계 |
| 노코드 빌더 (아임웹·Wix 등) | 빠른 제작, 한국형 템플릿, 폼·카카오 연동 쉬움 | 월 비용, 콘텐츠 이관성 낮음 |
| 직접 구축 (정적 사이트) | 자유도 최고, Claude로 제작 가능 | 도메인·호스팅·유지보수 직접 관리 |

**권고**: 1차는 **직접 구축(정적 사이트, Claude로 제작)** 또는 아임웹 중 선택. 이 저장소의 Mintlify는 세무 정보 블로그·매뉴얼 공개용으로 활용하고, 마케팅 홈페이지는 별도로 두는 것이 깔끔하다. 상담 폼은 카카오톡 채널로 시작하면 폼 백엔드가 필요 없다.

## 4.4 3개월 실행 플랜

**8월 — 기획**
- [ ] 구축 방식 확정 (직접 구축 vs 아임웹)
- [ ] 도메인 확보, 사무소명·로고 확정
- [ ] 사이트맵·페이지별 구성 확정
- [ ] 카카오톡 채널 개설

**9월 — 콘텐츠**
- [ ] 서비스 소개 3종(기장/아웃소싱/재산제세) 원고 작성
- [ ] 회계사 약력·사무소 소개 원고
- [ ] 요금 표기 방침 결정 및 요금 페이지 원고
- [ ] 블로그 첫 글 2건 작성 (예: 창업 시 세무 체크리스트, 양도세 셀프 체크)

**10월 — 구축·오픈**
- [ ] 사이트 제작·반응형 확인
- [ ] 상담 신청 동선 테스트 (폼/카카오톡)
- [ ] 검색 등록 (네이버 서치어드바이저, 구글 서치콘솔, 네이버 플레이스)
- [ ] 오픈 및 기존 고객·지인 공유
