# 1. 내부시스템 구축

> 목표: 3개월 안에 "거래처가 늘어도 흔들리지 않는" 운영 기반을 만든다.
> 우선순위: ① Airtable DB → ② CMS 수금 → ③ 기장 표준화 → ④ 스크래핑 정보 관리 → ⑤ 급여·성과급 구조 → ⑥ 자동화 확장

## 1.1 DB 관리 — Airtable 거래처 마스터

모든 내부시스템의 기초 데이터. 가장 먼저 구축한다.

**베이스 구성안 (테이블 5개)**

| 테이블 | 주요 필드 | 용도 |
|---|---|---|
| 거래처 | 상호, 사업자번호, 대표자, 업종, 법인/개인, 과세유형, 결산월, 담당자, 수임일, 상태(수임중/해지) | 마스터 |
| 신고일정 | 거래처(링크), 세목, 귀속, 기한, 상태(대기/진행/완료), 완료일 | 기한 관리 |
| 수수료·수금 | 거래처(링크), 월 기장료, CMS 출금일, 출금 결과, 미수 잔액, 세금계산서 발행 여부 | 수금 관리 |
| 접속정보 | 거래처(링크), 사이트(홈택스/위택스/여신협회/4대보험/은행/카드), 인증방식, 인증서 만료일, 수임동의 상태 | 스크래핑·위임 관리 |
| 업무태스크 | 거래처(링크), 업무 내용, 담당, 기한, 상태 | 일상 업무 |

## 1.2 CMS 수금 체계

기장료를 계좌이체·독촉에 의존하지 않고 CMS 자동이체로 전환한다.

**설계**
- CMS 대행사 선정: 금융결제원 CMS 또는 효성CMS·나이스 등 대행사 — 건당 수수료, 최소 약정, 전자 출금동의 지원 여부로 비교
- 출금일: 매월 25일 1회 (실패 시 말일 재출금)
- 신규 수임 시 계약서와 함께 CMS 출금동의서 수취를 표준 절차화
- 출금 결과를 Airtable 수수료·수금 테이블에 기록, 2회 연속 실패 시 유선 안내
- 세금계산서: 매월 출금 확정분에 대해 일괄 발행

**실행 태스크**
- [ ] CMS 대행사 2~3곳 견적 비교, 계약 (8월)
- [ ] 기존 고객 CMS 출금동의 수취 안내 발송 (8월 말)
- [ ] 9월분부터 첫 CMS 출금 실행, 결과 기록 루틴 확립 (9월 25일)
- [ ] 미수금 관리 규칙(재출금→유선→중단 기준) 문서화 (9월)

## 1.4 스크래핑 사이트 정보 관리

거래처별 사이트 접속·위임 정보를 한곳에서 관리한다 (Airtable 접속정보 테이블).

**관리 대상**
- 홈택스: 세무대리 수임동의, 신고 대리 범위
- 위택스(지방세), 4대보험 EDI, 여신금융협회(카드매출), 은행·카드 스크래핑(기장 프로그램 연동)
- 공동인증서: 보관 위치, 만료일, 갱신 담당

**보안 원칙**
- 사이트 계정·비밀번호는 Airtable 접속정보 테이블에서 통합 관리한다 (대표 결정 사항)
- 접속정보 테이블 접근 권한은 담당자로 한정하고, 직원 퇴사 시 해당 계정 비밀번호를 즉시 변경
- Airtable 계정 자체는 2단계 인증(2FA)을 활성화하고 공유 링크 생성을 금지
- 고객 개인정보 취급 원칙(수집 최소화·목적 외 사용 금지)을 문서화

**실행 태스크**
- [ ] 거래처별 접속·위임 현황 전수 조사 후 Airtable 입력 (8월)
- [ ] 비밀번호 관리 도구 선정·이관 (8월)
- [ ] 인증서 만료 알림 운영 시작 (9월~)

## 1.6 급여·성과급 배분 구조

채용 전에 구조를 먼저 확정해 채용 공고·면접·기존 인력 동기부여에 활용한다.

**설계안 (초안 — 사무소 손익에 맞게 조정)**

- 보상 = 기본급 + 담당 매출 성과급 + 신규 유치 인센티브 + 시즌 성과급
- **기본급**: 직급(수습/담당/선임)별 고정. 시장 수준을 조사해 설정
- **담당 매출 성과급**: 담당 거래처 월 기장료 합계가 기준선(예: 본인 인건비의 2.5배)을 넘는 초과분의 일정률(예: 10~20%)을 분기 지급
- **신규 유치 인센티브**: 본인 소개로 수임 계약 시 첫 3개월 기장료의 일정률(예: 50%) 지급
- **시즌 성과급**: 부가세·연말정산·법인세(조정) 시즌 처리 건수·품질 기준으로 지급 — 조정료 수입의 일정률 배분
- **평가 주기**: 매출·수금은 Airtable 데이터로 월 집계, 성과급 정산은 분기
- **원칙**: 산식은 단순하게, 데이터(Airtable 수수료 테이블)로 자동 계산 가능하게, 미수금은 성과급 산정에서 제외(수금 완료 기준)

**실행 태스크**
- [ ] 직급별 기본급 시장 조사 (9월)
- [ ] 성과급 산식 확정, 규정 문서화 (10월)
- [ ] Airtable에서 담당자별 매출 집계 뷰 생성 (10월)
