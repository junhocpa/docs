# 미수 안내 메시지 — 사용 매뉴얼 (담당자용)

이 프로젝트는 **미수(미납) 거래처에 보낼 안내 메시지**를 Claude가 자동으로 작성해
주는 프로젝트다. 데이터는 프로젝트에 연결된 **구글 시트**에서 가져오며, 금액은
**담당자가 확인·수정**한 뒤 확정한다.

---

## 1. 최초 1회 설정

1. **지침 등록**: 프로젝트 설정 → "지침(Instructions)"에 같은 폴더의
   `지침.md` 내용을 붙여넣는다.
2. **구글 시트 연결**: 프로젝트에 미수내역 구글 시트를 추가한다.
   - Claude.ai → 프로젝트 → "+ 추가" → Google Drive에서 해당 시트 선택
     (또는 시트 링크/내보낸 파일 첨부).
   - 미수내역이 갱신되면 같은 시트를 최신 상태로 유지하면 된다.
3. 시트 1행은 헤더여야 하고, 다음 컬럼이 있어야 한다:
   **회원명 · 회원번호 · 청구월 · 납부자 휴대전화 · 상품 · 결제일(납부기간) ·
   미납금액 · 비고 · 결제결과**.

---

## 2. 기본 사용 흐름

1. 채팅에 요청한다. 예:
   - "미수 안내 메시지 만들어줘" (전체 거래처)
   - "(주)하늘드림홀딩스 메시지 만들어줘" (특정 거래처)
2. Claude가 먼저 **거래처별 합산 확인표**를 보여준다
   (회원명 · 회원번호 · 건수 · 총 미수대금).
3. 담당자가 금액을 **확인하고 필요하면 수정**한다 → 3장 참고.
4. "확정" / "그대로 만들어줘"라고 하면 최종 메시지를 거래처별로 출력한다.
5. 출력된 메시지를 복사해 문자/카카오톡 등으로 발송한다.

---

## 3. 금액 확인·수정 (중요)

시트 금액은 **잠정값**이다. 발송 전 담당자가 반드시 확인한다. 수정 예시:

| 하고 싶은 것 | 이렇게 말하면 됨 |
|--------------|------------------|
| 총액 바꾸기 | "OO거래처 총 미수대금 500,000원으로" |
| 특정 줄 금액 수정 | "OO거래처 3월 기장료 143,000원으로" |
| 줄 빼기 | "OO거래처 1월 줄 빼줘" |
| 줄 추가 | "OO거래처 6월 월 기장료 165,000원 추가" |
| 부분 납부 반영 | "OO거래처 100,000원 입금됐으니 차감" |

Claude는 시트 값보다 **담당자가 불러준 값**을 우선한다. 수정 후 다시 확인표를
보여주므로, 맞으면 "확정"이라고 하면 된다.

---

## 4. 자동 적용되는 규칙 (요약)

- **회원명**: `주식회사`→`(주)`, `유한회사`→`(유)` 등 약식 표기.
- **금액**: 천 단위 콤마, 총액은 `*강조*`.
- **청구월/인출일**: `26년 5월`, `6월 4일` 형식.
- **상품**: `월세무기장료`→`월 기장료`, `결산조정료`→`결산조정료` 등.
- **실패 사유**: `잔액부족`→`인출 실패`, 카드 사유는 각각 문구로.
- **세무신고 항목**: 법인 `부가세, 원천세, 법인세 등` / 개인 `부가세, 원천세, 종소세 등`.
- **세금계산서 발급**: 시트 비고에 표기된 줄에만 `, 세금계산서 발급` 추가.
- **마무리 문구**: "...처리 가능한 일자와 방식(CMS / 이체 / 카드 - 개인카드 결제 가능)을 말씀 주시길..."

규칙을 바꾸고 싶으면 `지침.md`(프로젝트 지침)를 고치면 된다.

---

## 5. 자주 쓰는 요청 예시

- "이번 달 미수 거래처 전체 메시지 만들어줘"
- "3개월 이상 장기 미수만 골라서 메시지 만들어줘"
- "거래처별로 전화번호도 같이 표기해줘"
- "(주)하늘드림홀딩스만 다시 만들어줘"
- "발신처명을 □□세무회계로 바꿔서 만들어줘"

26년 1월 월 기장료 : 330,000원 (2월 3일 인출 실패)
26년 1월 월 기장료 : 165,000원 (2월 3일 인출 실패)
26년 2월 월 기장료 : 165,000원 (3월 6일 인출 실패)
