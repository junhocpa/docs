# 임경만 대표 통화 내용 정리

- 작성일: 2026-07-03
- 소개 경로: 서승건 이사 통해 연락처 수령, 메일 문의 후 통화
- 응대: 이준호 회계사 (솔루션택스)

## 1. 고객 개요

- 온라인 의류 브랜드 운영, 사업 5년차, 개인사업자
- 무신사 등 4~5개 플랫폼 입점 판매 (수수료 차감 후 월 정산 수령)
- 4대보험 직원 없음. 디자이너 등 프리랜서 3.3% 원천징수 용역 간헐 사용
- 사업장/거주: 강남(반포 인근) — 당소(선릉역 인근)와 근거리
- 기존 세무대리: 경기도 평택 소재, 지인 소개 회계사. 이커머스/플랫폼 비전문
- 홈택스에 사업용 카드 등록되어 있음. 일부 플랫폼(예: 삼성 관련)은 홈택스에 매출이 노출되지 않아 어드민에서만 확인 가능

## 2. 이관 사유 (핵심 세무 이슈)

- **판매자 부담 쿠폰이 매출에 포함되어 신고되는 문제**
  - 예: 10만원 상품 → 50% 할인 + 판매자 부담 쿠폰 10% 추가 → 실질 판매가는 4.5만원 수준인데, 쿠폰 적용 전 금액으로 매출 신고됨
  - 판매자 부담 쿠폰은 매출 에누리로 차감되어야 하며, 무신사도 가이드에 쿠폰 제외를 명시
- 기존 회계사는 "플랫폼이 신고한 금액(홈택스 노출액)보다 낮게 신고 불가" 입장을 고수, 어드민 공동 확인 요청도 거절 ("봐도 모르겠다")
- 당소 유사 사례: BBQ 프랜차이즈 배달앱(쿠팡이츠 등) 쿠폰 과다 신고 건 — 플랫폼 어드민 확인 + 경정청구로 환급 완료
- **과거 5년분 경정청구 검토 가능** (대표도 인지, 관심 있음)
- 진행 방식: 플랫폼 어드민 ID/PW 공유받아 당소가 직접 정산 구조 확인 (대표가 엑셀 정리해 주던 기존 방식 지양)

## 3. 기장료 협의사항

| 항목 | 협의 내용 |
|---|---|
| 월 기장료 | **월 10만원** (당소 기본 12~13만원이나 기존 수준 감안하여 합의) |
| 별도 고정 비용 | **종소세 조정료만 별도.** 부가세·원천세 신고는 기장료에 포함 |
| 기타 | 가결산 등 별도 이벤트 없으면 추가 비용 없음 |
| 기장 시작 | **7월분부터.** 6월분 원천세 신고는 당소에서 처리해 주기로 함 |
| 이관 절차 | 5월 종소세 신고는 기존 사무실이 마무리 후 이관 (기존 담당자가 이미 준비 중이었음). 대표가 기존 담당자 연락처를 문자로 송부 → 당소가 직접 연락해 자료 인수 |

### 고객이 기대하는 서비스 범위
- 부가세 신고 시 플랫폼 매출 구조(쿠폰·에누리) 정확 반영 — 최우선
- 향후 4대보험 직원 채용 시 급여 항목 설계, 근로계약 관련 자문 (제휴 노무법인 연계 가능 안내함)
- 브랜드 사용·홀세일 등 계약서 관련 자문 (세무·회계 관점 조언 가능, 본격적인 법무 검토는 제휴 법무 연계 안내함)
- 상속 관련 상담 (아래 5번)

## 4. 담당자 전달사항

1. **담당자 배정 완료** — 플랫폼 매출·경정청구 경험 있는 담당자 배정함. 회계사와 공동 관리
2. **자료 수령 채널**: 카톡 채널 추가 완료. 사진/이미지로 자료 수령 가능
3. **원천세 신고 (7/10 기한)**: 6월분 3.3% 사업소득 지급 **2건** → 7/10까지 원천세 신고·납부
   - 봉제공장 사장 건 약 200만원: 사업자 폐업 상태라 사업소득 3.3% 원천징수 처리. 주민등록번호 전체 자리·신분증·통장사본 수취 완료 (초기에 뒷자리 마스킹해서 보내는 등 협조 지연 있었음)
4. **기존 세무대리인 자료 인수**: 대표가 연락처 문자 송부 예정 → 수령 즉시 자료 요청
5. **부가세 신고 시 체크**: 판매자 부담 쿠폰 매출 에누리 차감 반영, 플랫폼별 정산 구조(플랫폼 부담 vs 판매자 부담 쿠폰, 마일리지 등) 구분. 과거분 경정청구 검토
6. **명함 전달** 완료 여부 확인

## 5. 상속등기 상담 건 (평택 주택)

- 부친 사망 후 약 5~6년 경과, **상속등기 미완료** (등기 여전히 부친 명의)
- 상속취득세(3%, 약 700만원)는 사망 직후 납부 완료, 재산세도 매년 납부 중 → 등기만 남은 상태
- 현재 부친이 하던 임대업을 대표가 그대로 운영 중이나, 등기 미완료로 **전세계약·매매·대출 모두 불가** → 시급
- 상속인: 4남매 (대표는 2남 2녀 중 장녀)
  - 막내 여동생: 관계 소원, 구두로는 권리 주장 안 하겠다고 함 — 단, 협의분할에는 **인감·동의 필요함을 안내**
  - 남동생 1명: 본인 명의 아파트 2채 보유로 공동등기 불원
- 내부 합의안: **대표 1인 단독(대표) 등기**, 내부적으로 5:3:2 분배. 남동생 1명이 지분 보장의 법적 장치를 요구 (대표는 내용증명 정도까지 가능하다는 입장)
- 안내한 내용:
  - 상속포기(상속개시 후 3개월)는 기한 경과 → **협의분할만 가능**, 상속인 전원 인감·동의 필요
  - 상속등기 자체는 법정 기한 없음 (매매등기 60일과 다름)
  - 단독등기 후 매각대금을 형제에게 분배하면 **양도세(지분 대가) 또는 증여세 이슈** 발생 가능 — 계좌이체 시 소명 문제 안내함
- 후속: 실무적으로 유리한 방안 법무사와 확인 후 회신 예정. 대표는 동생들과 세금 이슈 포함 재협의 후 상황 정리해 메일 또는 전화 상담, 필요시 대면. 제휴 법무사/변호사 연계 가능
