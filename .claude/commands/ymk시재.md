# 일일시재(日日時在) 작업 스킬

와이엠케이본사(회계단위 1000) 일일시재보고(26기)_반출.xlsx 의 당일 작업을 안내한다.
오늘 날짜: $CURRENT_DATE

---

## 기본 규칙

- **보고 기준**: 금일자로 "전일까지"의 자금현황 → 오늘 6/26 작업이면 **260625 시트** 생성
- **시트명**: `YYMMDD` 형식 (예: 260625). 맨 앞에 위치, 역순 정렬
- **B4 셀**: 시트명에서 자동 표시 → 직접 입력 금지
- **절대 불가침**: J·K·L열 수식, 소계행(10·19·28·35·36·38·41·45·6행) G/H/I, 외화 환율(K열)

---

## 매일 5단계 작업

### 1단계 — 새 시트 생성
전일 시트를 통째로 복사 → 시트명을 **보고기준일(YYMMDD)** 로 변경 → 맨 앞으로 이동

### 2단계 — 전일잔액 이월 (캐리포워드)
입력행 각각: **G(전일잔액) = 전일 시트 J(잔액) 값**으로 하드코딩

| 행 | 계좌 |
|---|---|
| 11 | 현금(社内) |
| 12 | 우리 710-483380-13-001 |
| 13 | 우리 710-483380-13-002 (평택사옥 대금정산) |
| 14 | MUFG S-K 100-081396 |
| 15 | IBK 607-009050-01-011 |
| 16 | 우리 큰만족법인MMF1호 |
| 17 | HANA 858-910005-87404 |
| 18 | 우리 단기채권투자신탁 |
| 20~27 | USD 계좌군 |
| 29~34 | JPY 계좌군 |
| 40 | 노무라 글로벌(장기) |
| 42~44 | AIA / 미국채 / J리츠 |
| 47 | 퇴직급여 |

> 소계행(10·19·28·35·36·38·41·45·6)의 G는 수식 → 손대지 않음

### 3단계 — 거래열·메모 초기화
입력행의 **H(입금)·I(출금)** 과 53행~ MEMO 영역 비우기
J·K·L 수식셀과 외화 환율(K열)은 그대로 유지

### 4단계 — 당일 거래 입력
통장/전표 기준으로 해당 계좌 행에 입력:
- 차변 보통예금(입금) → **H열**
- 대변 보통예금(출금) → **I열**
- 계좌번호 끝자리로 행 특정 (예: ...-002 → 13행)
- 같은 계좌 여러 건은 **합산** 후 한 셀 입력, 내역은 MEMO에 기록

### 5단계 — 검산 (3개 모두 0/일치 확인)
| 검증항목 | 조건 |
|---|---|
| L6 (차대검증) | = 0 |
| K6 (증감액) | = J6 − G6 (입금합 − 출금합과 일치) |
| J6 (자금현황⑧) | = J10(③단기합) + J38(⑥장기합) + J47(⑦퇴직급여) |

## 자금일보(ACD2050) 대사

### 조회 설정
ERP → 회계관리 → 자금관리 → **자금일보/결재(ACD2050)**
전표승인기간/확정기간 = **보고기준일 ~ 보고기준일**

### 대사 매핑
| 자금일보 | 일일시재 | 검증 |
|---|---|---|
| 계좌별 잔액 | 해당 행 J(잔액) | 전 계좌 일치 |
| 계좌별 감소 | 해당 행 I(출금) | 변동계좌 일치 |
| 계좌별 발생 | 해당 행 H(입금) | 변동계좌 일치 |
| 일일시재(장부) 당일말 | J6 − J47 | 핵심 합계식 |
| 퇴직연금 | 47행(J47) | 일치 |

**핵심 검증식**: 자금일보 「일일시재(장부)」 + 퇴직연금 = 일일시재 **J6(⑧자금현황)**

### 대사 완료 조건
- 전 계좌 잔액 일치
- 핵심 검증식 성립
- 일일시재 차대검증 L6 = 0

### 차이 발생 시 체크 순서
1. **전표 미승인** → 자금일보 미반영. 전표 승인 후 재대사 (가장 흔함)
2. **날짜 귀속 차이** → 다른 날 건이 섞임. 귀속일 재확인
3. **외화 환산 차이** → 환율·평가 반영 시점 차이
4. **입력 누락·오타** → 일일시재 H/I 입력값 점검

## 통장대조(ACB3010) 불일치 판별

월 단독 불일치 발생 시:
1. **분기(예: 4/1~6/30)로 기간 넓혀** 재조회
   - 통장 합계 = 원장 합계이면 → **타이밍 차이, 실차이 없음**
   - 불일치 계좌가 기간마다 달라지면 → 타이밍 현상 확정
2. 월 경계 구간(예: 5/20~6/5)으로 좁혀 **원장 기표일 ↔ 통장 입금일** 어긋남 확인

> 실차이 0이면 정정 불필요. 차액≠0이면 전표 점검.

## 주의사항

- **#REF! (O36)**: 전 시트 공통 과거 오류, 현금잔액 영향 없음. 복사 시 그대로 따라옴
- **퇴직급여(47행)** 출금칸은 평소 0 유지
- 파일은 **Excel에서 열면 전체 재계산** → J/소계/검증값 자동 채워짐
- 보안: Claude는 조회·읽기만. 로그인·이체·출금·결제 입력 불가

## 오늘 작업 안내

오늘($CURRENT_DATE) 작업 기준:
- 생성할 시트명: **전일 날짜를 YYMMDD 형식으로** (예: 오늘이 2026-06-26이면 → `260625`)
- 사용자가 전표 내역을 붙여넣으면 해당 계좌 행·금액을 매핑해 H/I 입력값과 검산 결과를 제시한다
- ERP 화면을 공유하면 자금일보 대사를 수행한다
