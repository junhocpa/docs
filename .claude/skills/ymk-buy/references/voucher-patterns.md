## 4. 통신·공과금 거래처 (국세청 전송 지연 관행)

SK텔레콤, LG유플러스(LG텔레콤), 삼천리, 한국전력공사, 아이디스파워텔, SK브로드밴드.
전표는 청구서 기준 선입력 → 홈택스-더존 대조에서 "전표에만 있는 차이"로 남는 게 정상. 보고 문구: "기존과 같이 국세청 전송 지연에 따른 차이로, 전표는 입력되어 있어 전송되면 일치합니다."

## 5. 삼천리(도시가스) 규칙

- 작성일 N월 1일 = **(N-1)월 사용분**. 품의 `N-1월 숙소 가스이용대금 (호수) / 삼천리`.
- 숙소(호수별 계량기: 116-404, 111-501, 210-1304, 204-902, 207-303, 202-103, 503-2001 등) → 5370000[PJ:장비공통/FD], 평택사옥 → 8370000. 대변 미지급금.
- 사옥 기본요금은 매월 공급가액 2,820(합계 3,102)으로 반복 — 금액으로 식별 가능. 숙소 호수는 고지서 없이 특정 불가 → 확인 요청.

## 6. 수정세금계산서 상쇄쌍 판정

1. 같은 거래처·같은 작성일의 미발행 건들을 부호 포함 합산 → **순액 0이면 상쇄쌍 후보**.
2. 분개장에서 원본(또는 재발행분)의 전표 처리 여부 확인 — 처리돼 있으면 "전표 불필요". 근거(전표번호·품의)를 남긴다.
3. 순액이 0이 아니면(예: -110M+100M=-10M 감액) 잔여 순액의 전표 반영 여부를 분개장 금액 검색으로 추적 — 없으면 **미반영 경고**.
4. 회계 영향이 없어도 부가세 합계표에는 전 매수 집계 필요 — 신고 반영 확인 문구를 넣는다.
