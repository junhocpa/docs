# 보고 메시지 템플릿

모든 메신저 발송용 메시지는 **코드블럭 안에 순수 텍스트**로 제공한다(굵은 글씨 `**`, 마크다운 서식 금지 — 복사·붙여넣기 용도). 안내문 밖에서 필요한 설명은 코드블럭 바깥에 쓴다.

## 1. 팀 메신저 일일 보고 (택스가이드 채널, 류재상 스타일)

### 거래가 있는 날

```
금일(M/D 기준) 일일시재 작성하였습니다.

- 현금 사용내역 N건 (면접비 지급)
- 우리001 > 입금 N건 (우리큰만족 매도) / 출금 N건 (계좌간 이체 002)
- 우리002 > 입금 N건 (계좌간 이체 001) / 출금 N건 (6월 대금정산, 기숙사 관리비, 수입관세납부, 해외송금 수수료 등)
- 우리큰만족법인MMF1호 매도 N건
- 우리USD > 입금 N건 (대금입금 SDV) / 출금 N건 (계좌간 이체 USD MMDA 712119)
- 우리USD MMDA 712119 > 입금 N건 (계좌간 이체 우리USD) / 출금 N건 (대금정산 베트남 초청장 발급대금)
- 우리JPY > 입금 N건 (대금입금 YMJ 6월 청구분)
- 삼성증권 J리츠 맞춤형 WRap 전액매도 (운용수수료 및 매도 장부가액 출금 2건, 잔액 0)

기타 일일시재 폴더 최신화된 사항 없으며, 은행 홈페이지 계좌 잔액 및 자금일보와 대조 완료하였습니다.
일일시재 파일 수식 이상 없습니다.
```

**작성 규칙**:
- 계좌 순서는 시트 행 순서(현금 → 원화 → USD → JPY → 장기/증권).
- 각 항목은 `계좌명 > 입금 N건 (요지) / 출금 N건 (요지)`. 건수는 분개장 라인 수 기준, 요지는 대표 거래처·용도만 간단히.
- 계좌간 이체는 상대 계좌를 괄호에 명시.
- 시트 구조 변경(행 신설 등)이 있으면 마무리 문단에 한 줄 추가: `일일시재 시트에 ○○ 행 신설하였습니다 (사유).`
- 마무리 문구는 실제 수행한 검증 범위에 맞춰 조정 — 은행 잔액 대조를 안 했으면 그 부분을 빼고 "자금일보와 대조 완료하였습니다"만.

### 변동이 없는 날

```
금일(M/D 기준) 일일시재 변동사항 없습니다.
```

실잔고 대조까지 한 경우 선택적으로:

```
금일(M/D 기준) 일일시재 변동사항 없습니다.
은행 및 삼성증권 실제 잔고와 대조하여 거래 없음 확인 완료하였습니다.
```

## 2. 고객(YMK) 안내문 — 검증 결과 통보

구조: 인사 → 검증 개요(무엇을 무엇과 대조했는지) → [대조 결과] 결론 먼저 → 계좌별 일치 내역 → [참고] 차이가 있으나 정상인 항목(발생일 분리, 기중 미평가) → [확인 요청] → 맺음. 존댓말, 숫자는 천단위 콤마, 통화 단위(원/불/엔) 명기.

```
안녕하세요. 와이엠케이 담당자님, 솔루션택스입니다.

M월 D일자 ERP 거래내역이 확인되지 않아, M월 D+1일 조회된 실제 잔고(우리은행 원화/외화, 하나은행, 삼성증권)와 일일시재(M/D-1 기준)를 전 계좌 대조한 결과를 안내드립니다.

[대조 결과] M월 D일에는 거래가 없었던 것으로 확인됩니다.
- 우리은행 원화: 001계좌 ○원 / 002계좌 ○원 / 큰만족MMF ○원(장부가) 일치
- 우리은행 외화: USD MMDA ○불 / JPY MMDA ○엔 / JPY통장 ○엔 일치
- 하나은행: ○원 일치
- 삼성증권 예탁계좌: 원화 ○원 / USD ○불 / JPY ○엔 일치
- 은행 최종거래일 기준으로도 M/D자 거래가 기록된 계좌는 없습니다.

[참고 1] ○○계좌는 실제 잔고가 시재 대비 ○ 차이가 있으나, 최종거래일이 M/D+1로 확인되어 M/D+1자 입금(이자로 추정)입니다. M/D+1 일일시재에 반영하겠습니다.

[참고 2] 투자자산은 기중에 평가하지 않으므로 장부가와 조회 평가액 간 차이가 있으며 이는 정상입니다. (결산 시 일괄 반영)

[참고 3] 잔고자료에 포함되지 않은 계좌(○○)는 대조 대상에서 제외하였습니다.

[확인 요청] (있을 때만) 일일시재 관리 대상 외 계좌가 확인되어 성격 확인을 부탁드립니다.
- 계좌번호 (상품명, 가입일, 평가액)

감사합니다.
솔루션택스 드림
```

## 3. 오류 발견 시 보고 (사용자에게)

메시지 요청과 함께 시재 오류를 발견하면, **안내문보다 먼저** 오류를 보고한다: 수정할 셀 주소·현재값·올바른 값·수정 후 총잔액(검산 포함)을 제시하고, "수정 후 발송" 전제를 명시한다. 예: `G45에 0 입력 → 수정 후 J6 = 44,076,165,493 (= 전일 잔액 + 당일 입금, 검산 일치)`.
