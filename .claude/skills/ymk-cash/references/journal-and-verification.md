## 1. 분개장 읽기

더존 분개장 그리드 엑셀(`ACA0050Grid_excel_YYYYMMDD_HHMM.xlsx`)은 openpyxl이 스타일 파싱 버그로 못 연다. calamine으로 읽는다:

```python
import pandas as pd
cols = {0:'date',1:'no',2:'dr_amt',3:'dr_acct',4:'cr_acct',5:'cr_amt',
        6:'desc',7:'vcode',8:'vname',36:'pumui'}
df = pd.read_excel(path, engine='calamine', header=None, skiprows=1)
df = df[list(cols)].rename(columns=cols)
df = df[df['date'] == '2026-08-05']          # 대상 승인일 (마지막 '합계' 행 자동 제외)
```

- 한 전표(승인번호)가 여러 라인(차변/대변 각각)으로 나온다. 차변 라인은 `dr_acct/dr_amt`, 대변 라인은 `cr_acct/cr_amt`만 채워져 있다.
- 같은 날 분개장이 여러 번 출력된 경우 **시간이 늦은 파일이 최신**. 라인 수·차대합이 같아도 개별 금액(적용환율)이 다를 수 있으니 최신본으로 대사한다.
- 월간 분개장과 일일 분개장이 함께 있으면 해당 일자 라인끼리 완전 일치하는지 교차 확인(전표번호 집합·차대합).

## 3. 검증 체크리스트 (작성·검증 공통 — 전 단계 수행)

1. **이월 대조**: 당일 시트 G열(전일잔액) = 전일 시트 J열(잔액). **전 계좌 행**에 대해 비교 — 잔액 0이 된 계좌(전액매도)·신설 행이 누락 단골. 불일치 시 `G45=8,026,510,632 vs 전일 J45=0` 식으로 특정.
2. **분개장 대사**: 위 매핑으로 (계정, 거래처)별 차/대 집계 = 시트 H/I. 전 계좌 일치해야 함.
3. **K열 재계산**: 외화 계좌별 전일 K ± 당일 외화 증감 = 당일 K. 전액매도 계좌는 0.
4. **수식 체인 독립 재계산**: J=G+H-I, 합계행 SUM 범위(행 삽입 시 자동 확장 여부), 총계 J6, K6=J6-G6, **L6=0**. Python으로 상수만 가지고 전체를 재계산해 캐시값과 대조하는 것이 가장 확실.
5. **자금일보(HTML) 대조**: dzeditor HTML의 계좌별 전일/입금/출금/잔액과 시트 값 비교. 총계 관계식: **자금일보 당일말시재액 + 퇴직연금 = 시재 J6** (ERP 시재는 퇴직연금 제외). ERP는 예탁계좌 외화보통예금을 통합 표시 → 시트의 원화(18행)+USD(26행)+JPY(33행)를 합산해 비교.
6. **다른 시트 불가침**: 대상 시트 외 전 시트를 해시(셀 값 문자열 연결의 sha256)로 전후 비교 — 변경 0이어야 함.

## 4. 실잔고 대조 (무거래 검증)

"N일 거래내역이 없는데 실제로 없었는지 확인" 요청 시: 시재 최종 시트 잔액 vs 조회일 실제 잔고를 계좌별 대조한다.

**대조 자료별 위치**:
- 우리은행 전계좌조회(원화): 계좌번호·잔액(원). MMF는 잔액(원)=장부가, 좌수·기준가·평가금액 별도(평가금액 차이는 기중 미평가로 정상).
- 우리은행 외화계좌조회: 계좌번호·통화·잔액(외화) → 시재 K열과 비교.
- 하나은행 계좌목록: 잔액(원).
- 삼성증권 잔고 PDF: 계좌별 매입/평가금액(투자자산 — 참고용), **외화예수금 섹션의 JPY/USD 잔액**과 원화예수금 → 시재 예탁계좌 행들과 비교. 한글이 깨져도 계좌번호·숫자로 식별 가능.

**판정 원칙**:
- 예금성(보통예금·MMDA·예수금·MMF 장부가/좌수)은 **정확 일치**해야 검증 통과.
- 투자자산(주식·채권·신탁 평가액, MMF 평가금액, 퇴직연금 평가액)의 차이는 기중 미평가 원칙상 **정상** — 문제로 보고하지 않고 참고로만 명시.
- 차이가 있으면 **최종거래일**을 본다. 검증 대상일이 아닌 날짜(예: 조회 당일 아침 이자입금)면 그날 거래가 아님 → "M/D자 입금(이자 추정), M/D 시재에 반영 예정"으로 분리 보고.
- 은행 최종거래일 중 검증 대상일이 하나도 없으면 "해당일 거래 없음"의 교차 근거가 된다.
- 잔고 자료에 있으나 시재 관리 대상에 없는 계좌(신탁 등)는 성격 확인 요청으로 별도 보고.
- 자료가 제공되지 않은 계좌(사내현찰·MUFG·IBK·노무라·AIA 등)는 "대조 범위 외"로 명시.
- 만기일이 임박한 상품(신탁 만기 등)이 보이면 예정 이벤트로 알려준다.
