# 일일시재 시트 구조

워크북은 영업일마다 시트 1장(`YYMMDD`, 최신이 맨 앞) + `작업가이드 시트` + `검증`(분기말 기말평가 비교용)으로 구성된다. 제목은 `▣ 日 日 時 在 報 告`, B4의 날짜는 시트명에서 파생되는 수식(`CELL("filename")` 기반)이므로 건드리지 않는다.

## 작업가이드 시트의 3원칙 (원문 요지)

1. 기존 시트에서 수식이 걸려 있던 부분은 **수식 변형 없이** 그대로 둘 것.
2. 시트 복사 시: 복사 원본(전일)의 최종 잔액(J열)을 새 시트의 전일잔액(G열)에 **하드코딩**.
3. 복사 후 메모·거래내역은 삭제하되, 수식 부분과 **K열 포함 우측 값은 복사 단계에서 건드리지 말 것** (외화잔액이 이월되도록). 거래 반영 단계에서는 외화 증감에 따라 K를 갱신하는 것이 관례.

## 열 구조

| 열 | 내용 | 입력 방식 |
|---|---|---|
| G | 前日残額 (전일잔액) | 하드코딩 (전일 J) — 합계행만 수식 |
| H | 入金 (입금) | 계정행: 상수 또는 `=+E<메모행>` 참조 (최신 구조) |
| I | 出金 (출금) | 계정행: 상수 또는 `=+J<메모행>` 참조 |
| J | 殘額 (잔액) | 수식 `=G+H-I`, 합계행은 SUM |
| K | 외화잔액 / 增減額 | 외화 계정행: 외화 금액 하드코딩. K6은 `=J6-G6` 수식 |
| L | L6 = 검산 `=(G6+H6-I6)-J6` → **0이어야 함** | 수식 |
| M | 환산단가 `=J/K` | 수식 (K=0이면 #DIV/0! — 잔액 0 계좌의 정상 표시) |
| N~ | 비고 등 | 건드리지 않음 |

## MEMO 작성 관례 (B53 `MEMO` 아래)

- **입금 블록**: B열에 `*입금내역(계좌명)` 헤더(굵게), 아래 B열에 내역, **E열에 금액**(굵게, 회계서식).
- **출금 블록**: G열에 `*출금내역(계좌명)` 헤더, 아래 G열에 내역, **J열에 금액**.
- 블록 사이 빈 행 1개. 한 블록에 2건 이상이면 마지막에 소계(값 또는 `=+SUM(...)`).
- 폰트: 돋움 11pt. 헤더·금액 굵게, 내역은 보통.
- **외화 표기**: `USD 1,170*1,466.21`, `JPY 5,149,538*9.0213` (외화금액*적용환율). 수수료가 차감된 입금은 `(수수료 32.99)` 병기.
- **계좌간 이체**는 출금측·입금측 양쪽 블록에 모두 기재.
- 소액 다건 출금은 `대금정산 기타(기숙사·관리비·지방세 등 N건)`처럼 묶고, 큰 건(월 대금정산·급여·세금)은 개별 기재.
- 수입관세는 `26.MM.DD 수입관세납부 N건`, 해외송금 수수료는 `해외송금 수수료 N건` 관례.
- 현금 사용은 `YYYY.MM.DD 면접자 N명 면접비 지급` 식으로 일자 포함.
- 최신 구조에서 본표 H/I가 이 메모 금액 셀을 `=+E55`/`=+J60` 형태로 직접 참조한다 — 메모 금액이 곧 원장값이므로 셀 위치를 바꾸면 참조가 깨진다.

## 자주 나오는 거래 패턴

| 패턴 | 시재 반영 |
|---|---|
| MMF 매도 | MMF 행 출금=장부가(원금), 입금 계좌 H=원금+이자−원천세(선납세금14%+지방10%). 메모 `우리큰만족법인매도 KRW <원금>` |
| 계좌간 이체 | 양쪽 행에 동액 입·출금, 외화면 K도 양쪽 증감 |
| 외화 대금입금 | H=원화환산액, K += 외화금액, 메모에 `외화*환율(수수료)` |
| 해외송금 | 외화 계좌 I=환산액·K −= 외화, 우리002에서 송금수수료 8,000원/건 별도 출금 |
| 증권 전액매도 | 해당 행 I=장부가 전액(운용수수료 포함), K=0, 매도대금은 예탁계좌(JPY/USD)로 입금, 원화 끝전은 예탁계좌 원화 행 |
