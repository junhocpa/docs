# YMK 마스터데이터 (참고값)

거래처·PJT 코드는 **항상 원본/마스터/분개장으로 확인**한다. 아래는 자주 쓰이는 확정 매핑이며, 임의 디폴트값으로 채우지 않는다.

## 1. 거래처 코드 (재고수불 빈출)
| 회계코드 | 거래처명 | 비고 |
|---|---|---|
| `03340` | 에이엔티(ANT) | 인벤코드 51165, 사업번호 122-19-77121 |
| `00321` | 요도가와메덱(일본) | 인벤코드 31311, 사업번호 더미값(1111111111)/해외 — 통화 확인 |
| `07092` | 브라이트코리아 | 동일명 미사용코드(8072) 존재 → 사용중 코드만 |

거래처 마스터(`YMK_거래처_리스트`)가 있으면 그것을 우선한다. 없으면 분개장에서 거래처명으로 `거래처코드` 확인(5자리 zero-pad).

## 4. PJT 코드 (재고수불 빈출/특수)
| 코드 | 의미 | 처리 |
|---|---|---|
| `000001` | 장비공통 | 규칙 2 전기재고 강제변환 목적지 |
| `000092` | 전기프로젝트 | 규칙 4 26기 PJT 변환 목적지 |
| `021101` | SEC향 Panel Carrier Attach_ESFM0301L | 27기 정상 |
| `071401`/`071402` | 신규 MNT 부착기류 | 27기 정상 |

**PJT 코드는 6자리 영문자리 zero-pad** (예: 1 → `000001`, 21101 → `021101`).

주의 케이스:
- `8004`/`8005`/`60205`/`280102` 등은 재고·스페어성 또는 26기/리스트외 PJT일 수 있음. 전기재고면 규칙2로 `000001` 강제변환되어 소멸, 상품대체면 규칙5로 공란 처리되어 전표에 미노출되는 경우가 많다.
- 리스트 외 PJT(마스터에 없음)는 ④PJT매핑 시트에 노란색 강조 + "확인필요" 표기. 25기 이전 PJT면 92 수동 변환 검토.

## 5. 입력 데이터 특이사항
- 재고현황(출고현황): 제목행 + 대/소분류 병합 2행 헤더. `skiprows=3` 후 컬럼 수동 지정. 주요 컬럼: 구분·출고일자·출고전(구분/PJT코드/PJT명)·출고후(구분/PJT코드/PJT명)·재고일자·품명·출고수량·재고금액·코드·거래처명.
- 분개장(`YMK분개장_...`): 컬럼 = 승인일·승인번호·차변금액·차변계정·대변계정·대변금액·적요·거래처코드·거래처명·작성일·PJT코드·PJT명·부서코드·부서명·품의내역. 규칙 9 참조 조회 및 거래처코드 확인에 사용.
- 일부 마스터(거래처/프로젝트현황표)는 HTML형 `.xls`로 제공될 수 있음 → `pd.read_html(encoding="euc-kr")` 또는 그룹헤더 스킵(`header=1`) 필요.
