# 더존 자동전표 19컬럼 정의 + 산출 워크북 구조

## 1. 더존 자동전표처리(일반) 19컬럼 (A~S)

업로드 파일은 이 19컬럼만 사용한다(A~S). 산출 워크북에는 우측에 참조 보조컬럼 T~V를 두되 업로드 시 제외한다.

| 컬럼 | 한글명 | 영문코드 | 타입 | 필수 | 입력 규칙 |
|---|---|---|---|---|---|
| A | 작성일자 | MENU_DT | 문자(8) | ✓ | YYYYMMDD = 출고일자 |
| B | 회계단위 | IN_DIV_CD | 문자(4) | ✓ | `1000`으로 설정 (★ YMK 회계단위 확인 후 수정) |
| C | 사업장 | M_DIV_CD | 문자(4) | | 선택 입력 |
| D | 프로젝트/부서코드 | MGT_CD | 문자(10) | | 6자리 zero-pad PJT (★ 상품계정 공란) |
| E | 발행일 | ISSUE_DT | 문자(8) | | 어음 발행일(해당없음) |
| F | 작성번호 | MENU_SQ | 숫자(5) | ✓ | 일자별 1,2,3... (기존 전표와 충돌 방지) |
| G | 라인순번 | MENU_LN_SQ | 숫자(5) | ✓ | 전표 내 1,2,3... |
| H | 계정과목 | ACCT_CD | 숫자(7) | ✓ | 상품 `1460000` / 원재료 `1490000` / 경상연구개발비(제조) `523` 계열(규칙 10, 7자리 코드 더존 확인) |
| I | 차대구분 | DRCR_FG | 숫자(1) | ✓ | `3`=차변 / `4`=대변 |
| J | 적요 | RMK_DC | 문자(80) | | 규칙 8 표준문구 |
| K | 계정금액 | ACCT_AM | 숫자(17,4) | ✓ | 원 단위(소수점 반올림) |
| L | 거래처 | TR_CD | 문자(10) | | 회계 거래처 5자리 zero-pad (예: `03340`) |
| M | 사용부서 | CT_DEPT | 문자(10) | | `2000`=FD사업부 (★ 상품계정 공란) |
| N | 프로젝트 | PJT_CD | 문자(10) | | 6자리 zero-pad PJT (★ 상품계정 공란, 26기는 `000092`) |
| O | 품의내역 | ISU_DOC | 문자(100) | | 규칙 6: `타계정대체` or `타프로젝트대체` |
| P | 전표유형 | DOCU_TY | 문자(1) | | `1`=일반 |
| Q | 수출신고번호 등 | CT_NB | 문자(35) | | 공란 |
| R | 환종 | DUMMY1 | 문자(20) | | 공란 |
| S | 외화금액 | CASH_AM | 숫자(17,4) | | 공란 |

**참조 보조컬럼 (업로드 제외)**
| T | 전표복사 참조일 | 규칙 9. 전표 첫 라인에만 |
| U | 참조 전표번호 | 규칙 9 |
| V | 참조유형 | 규칙 9 (상품대체/원재료 타계정대체 등) |

전표 그룹핑: 같은 일자+거래처는 하나의 전표(MENU_SQ)로 묶고, 라인순번(MENU_LN_SQ)으로 구분. MENU_SQ는 일자별로 1부터 시작.

★ **타계정구분은 19컬럼에 없다** — 더존 전표입력 화면의 관리항목이므로 업로드/전표복사 후 별도 지정하고, 계정별 상세원장에서 전수 확인한다(규칙 11: 타계정대체 차변 `1.입고`/대변 `2.출고`, 타프로젝트대체 공란).

## 2. 산출 워크북 6시트 구조

파일명: `YMK_재고수불_자동전표_YYYY년MM월_v1.3.xlsx`

- **①요약** — 처리 건수/라인수/금액합/차대검증/거래처매칭/92변환/전기재고변환/상품공란/회계단위 확인/전표복사 참조 요약 + 일자별 분개표(참조 컬럼 포함).
- **②자동전표업로드** — A~S 더존양식(2행 헤더: 한글명 + 영문코드) + T~V 참조보조컬럼(회색). 하단에 차변합계/대변합계/차이(0) 검증 수식. "T~V 업로드 제외, A~S만" 안내 문구.
- **③거래처매핑** — 인벤코드/거래처명/회계코드/사업번호/상태/건수/금액합/특이사항. 해외·더미·미사용코드 강조.
- **④PJT매핑** — 사용 PJT 목록, 26기→92 변환 건수, 전기재고 강제변환(규칙2), 소멸(무시) PJT 표기.
- **⑤분개검토표** — ②와 동일 내용의 가독성용. 전표복사 참조(일자/번호) 컬럼, 원본 출고전PJT, 대표품명, 변환/특이 포함. 차변 연파랑/대변 연주황 음영.
- **⑥월별계정변동** — 계정과목별(상품/원재료/연구개발비) 건수·금액·비중. 합계행.

## 3. 서식 규칙
- 헤더: 진파랑(`305496`) 배경 + 흰색 글자. 영문코드 서브헤더는 연회색.
- 합계행: 노란색(`FFE699`).
- 차변 라인: 연파랑(`DDEBF7`) / 대변 라인: 연주황(`FCE4D6`).
- 참조 보조컬럼(T~V): 회색(`EDEDED`).
- 폰트: 맑은 고딕.

## 4. 코드 선행 0 보존 (필수)
작성일자(A)·회계단위(B)·프로젝트/부서(D)·거래처(L)·프로젝트(N) 등은 문자열로 입력하고 해당 셀에 텍스트 서식(`number_format='@'`)을 적용한다. openpyxl 저장 → recalc.py 재계산 후 `03340`, `000001`, `20260515`가 유지되는지 반드시 재확인(숫자 변환 시 `3340`, `1`로 깨짐).
