# YMK 재고수불 자동전표 처리 (지침 v1.2)

매월 더존 ERP 재고현황(출고현황)에서 회계처리가 필요한 변동을 뽑아 자동전표로 일괄 업로드하기 위한 표준 작업 절차다. 회계처리는 **타계정대체**(전기대체/상품대체/연구개발비대체/원재료대체) 또는 **타프로젝트대체**로 분류된다.

이 문서는 워크플로우 전체와 핵심 규칙 요약을 담는다. 세부 규칙·양식·마스터데이터는 `references/`를 필요할 때 읽는다:

- `references/rules.md` — 핵심 규칙 9가지 전체 (반드시 처리 전에 정독)
- `references/columns-and-output.md` — 더존 19컬럼 정의 + 산출 워크북 6시트 구조
- `references/master-data.md` — 거래처코드·PJT코드·계정과목·사업부코드 마스터
- `scripts/build_voucher.py` — 워크북 생성 템플릿(선행 0 보존·차대검증·참조컬럼 포함)

---

## 트리거와 입력

**트리거**: "재고수불 정리해줘", "재고수불 자동전표 처리해줘", "/ymk재고수불", 또는 재고현황/출고현황 엑셀 업로드 + 월간 전표 작성 요청.

**필수 입력**
- 재고현황(출고현황) 엑셀 — 더존에서 추출. 헤더는 병합 2행 구조(제목행 + 대분류/소분류). `skiprows=3` 후 컬럼 수동 지정 권장.
- 분개장(`YMK분개장_...`) — 규칙 9(전표복사 참조) 조회 + 거래처코드 확인용.

**보조 입력(있으면 사용, 없으면 분개장/마스터로 대체)**
- 거래처 마스터(`YMK_거래처_리스트`) — 규칙 7 거래처 자동매칭. 없으면 분개장에서 거래처명→코드 확인.
- 프로젝트현황표(26기/27기) — 리스트 외 PJT 판별.

**대상월 판단**: 추출일이 다음달 1일이면 대상월 = 전월(예: `20260601` 추출 → 5월분). 확실치 않으면 사용자에게 확인.

**매월 변경 파라미터** (처리 전 확정):
```
TARGET_YEAR = 2026 ; TARGET_MONTH = 5
CURRENT_FY_START = "2026-04-01"   # 당기 시작일
CURRENT_FY_NO = 27                # 당기 회계기수
```

## 작업 STEP 12단계

1. **ERP 자료 추출/로드** — 재고현황(출고현황) 로드. 병합헤더 주의(`skiprows=3` + 컬럼 수동 지정). 출고일자·재고일자 datetime 변환.
2. **1차 필터링 (규칙 1)** — 구분=`일반`, 출고일자=전월, 재고금액≠0, [출고전·후 PJT+계정 동일 & 재고일자 당기]인 행 제외(단 계정변환·전기재고는 포함). 미일반은 전량 제외.
3. **전기재고 변환 (규칙 2)** — 재고일자<당기시작이면 출고전 계정→원재료(1490000), PJT→`000001`.
4. **회계처리 분류 (규칙에 따라)** — 전기대체/상품대체/연구개발비대체/원재료대체/타프로젝트대체 결정. 분류표는 `references/rules.md`.
5. **분개 통합 (규칙 3)** — ★ **변환 후 최종 전표 라인**의 `[작성일자+계정+거래처+프로젝트+차대구분]`이 같으면 1라인 합산. 원본 출고전/후 PJT가 달라도 변환 후 키가 같으면 합산. 통합건은 검토표에 "N건 통합" 표기.
6. **거래처 자동매칭 (규칙 7) + 전표복사 참조 조회 (규칙 9)** — 거래처명→회계코드(5자리) 매핑 + 특이사항 검출. 분개장에서 유형별 최근 유사 전표의 [승인일+승인번호] 조회.
7. **26기 PJT 변환 (규칙 4)** — 26기 코드→`000092`(전기프로젝트), 적요 끝에 `| 원PJT ...` 추가.
8. **상품계정 처리 (규칙 5)** — 상품(1460000) 라인은 D(프로젝트/부서코드)·M(사용부서)·N(프로젝트) 모두 공란.
9. **품의내역 입력 (규칙 6)** — `타계정대체` 또는 `타프로젝트대체` 둘 중 하나.
10. **검증 시트 검토** — 거래처매핑·PJT매핑 강조사항(노란/붉은) 확인.
11. **더존 업로드용 분리** — 자동전표업로드 시트에서 ★ **A~S열만** 저장(T~V 전표복사 참조 컬럼 제외) → 더존 자동전표처리(일반) 업로드. 또는 참조 전표를 전표 복사로 불러와 금액·PJT만 수정.
12. **사후 검증** — 더존 계정별 상세원장에서 차/대변 합계 확인(타계정대체: 차=대 / 타프로젝트대체: 합계=0).

## 핵심 규칙 9가지 (요약 — 전체는 references/rules.md)

1. **의미있는 데이터 필터링** — 일반/전월/금액≠0 + [PJT·계정 동일 & 당기]는 제외.
2. **전기재고 처리** — 재고일자<당기시작 → 출고전을 원재료(1490000)/PJT `000001` 강제변환.
3. **분개 통합** — 변환 후 최종 라인의 [일자·계정·거래처·PJT·차대] 동일 시 1라인 합산.
4. **26기 PJT→92** — 26기 코드→`000092`(전기프로젝트), 적요에 원PJT 기재.
5. **상품계정 공란** — 상품(1460000) 라인은 PJT/부서 3개 컬럼 공란.
6. **품의내역 단순화** — `타계정대체` / `타프로젝트대체` 두 종류만.
7. **거래처 자동매칭** — 거래처명→5자리 코드, 미사용코드/더미 사업번호/해외 자동 검출.
8. **적요 표준문구** — 차변 `타계정에서 대체액` / 대변 `타계정으로 대체액` (타프로젝트는 `타프로젝트로 대체(+/-)`).
9. **전표복사 참조** — 분개장에서 유형별 최근 유사 전표 [승인일+번호]를 조회해 참조 기재. ②시트 T~V 보조컬럼(업로드 제외).

## 산출물

**워크북**: `YMK_재고수불_자동전표_YYYY년MM월_v1.2.xlsx` — 6시트: ①요약 ②자동전표업로드(A~S 더존양식 + T~V 참조보조) ③거래처매핑 ④PJT매핑 ⑤분개검토표 ⑥월별계정변동.

시트 구조·서식·19컬럼 정의는 `references/columns-and-output.md` 참조. 생성은 `scripts/build_voucher.py` 템플릿을 이번 달 데이터로 채워 실행.

**필수 검증**: 차변합계 = 대변합계 (차이 0). 코드성 컬럼(작성일자·거래처·PJT·회계단위)은 선행 0이 보존되도록 텍스트로 저장(아래 함정 참고).

## 흔한 함정 (반드시 유의)

- **선행 0 소실**: 거래처 `03340`, PJT `000001`/`000092`, 작성일자 `20260515`가 숫자로 저장되면 `3340`, `1`로 깨진다. 값을 문자열로 넣고 해당 셀에 텍스트 서식(`@`)을 적용한다. LibreOffice 재계산(recalc.py) 후에도 유지되는지 재검증.
- **병합 2행 헤더**: 재고현황은 제목행+대/소분류 2행 병합. 무심코 `header=0`으로 읽으면 컬럼이 어긋난다.
- **T~V열 업로드 금지**: 전표복사 참조(T/U/V)는 더존 업로드 대상이 아니다. 업로드 파일은 A~S열만.
- **전표번호는 일자별 재시작**: 규칙 9 참조 전표는 일자만이 아니라 계정·유형까지 같은 최근 전표로 매칭.
- **원본 임의 채움 금지**: PJT/거래처는 원본·마스터·분개장으로 확인. 추정 시 검토표에 "확인필요" 표기.
- **openpyxl 편집 후 수식 캐시**: 값 편집 시 수식 셀 캐시가 날아가므로, 텍스트 서식 적용 등 후처리 뒤 `recalc.py`로 재계산.

`recalc.py` 경로: `/mnt/skills/public/xlsx/scripts/recalc.py` (Claude.ai 파일생성 환경). Claude Code 등 로컬 환경에는 없을 수 있음 — 아래 "환경별 실행" 참조.

## 환경별 실행 (Claude.ai / Claude Code 공통)

이 스킬은 Claude.ai(파일 생성 기능)와 Claude Code(로컬 터미널) 양쪽에서 동작한다. 스크립트 경로는 항상 `${CLAUDE_SKILL_DIR}/scripts/build_voucher.py`로 참조한다(설치 위치에 무관하게 해석됨).

**산출물 경로**: `scripts/build_voucher.py`는 출력 폴더를 자동 선택한다 — 환경변수 `YMK_OUTPUT_DIR`가 있으면 그것, 없고 `/mnt/user-data/outputs`가 있으면(Claude.ai) 그것, 둘 다 없으면 현재 작업폴더. 로컬에서 특정 폴더로 저장하려면 `YMK_OUTPUT_DIR=./out python scripts/build_voucher.py`처럼 지정한다.

**수식 재계산**(SUMIF 등 합계 캐시값 채우기):
- Claude.ai: `python /mnt/skills/public/xlsx/scripts/recalc.py <파일>`
- Claude Code(로컬): recalc.py가 없으면 LibreOffice로 대체 — `soffice --headless --calc --convert-to xlsx --outdir <폴더> <파일>`. LibreOffice가 없으면 재계산은 생략 가능(엑셀에서 파일을 열면 수식이 자동 계산됨). 다만 재계산 없이도 차대검증 값은 스크립트가 콘솔에 출력한다.

**의존성**: `pip install openpyxl pandas`. pandas는 재고현황·분개장 로드에 사용.
